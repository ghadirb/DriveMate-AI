# DriveMate AI / همراه راننده

دستیار رانندگی فارسی با تمرکز روی فرمان صوتی، راهنمایی صوتی آفلاین و حداقل لمس صفحه.

## امکانات نسخه اول

- صفحه اصلی مینیمال بدون نقشه بزرگ
- ذخیره خانه، محل کار و مکان‌های دلخواه با GPS
- مقصدهای محبوب و مقصدهای اخیر
- فرمان صوتی فارسی مثل «برو خانه»، «اینجا خانه است»، «بلندتر صحبت کن»
- ذخیرهٔ لینک اشتراک‌گذاری‌شده از Google Maps و نشان با نام دلخواه
- پخش ۴۳ فایل WAV آفلاین
- مسیریابی با API نشان و fallback به map.ir
- ساختار آماده برای افزودن سرویس مسیر جدید
- نقطه اتصال آماده برای پاسخ‌های هوشمند فقط در شرایط خاص

## کلیدهای آنلاین و سرویس‌های واقعی

برنامه در شروع، فایل رمزگذاری‌شدهٔ کلیدها را ابتدا از `abrehamrahi.ir` و در صورت خطا از Gist دریافت می‌کند. رمزگشایی دقیقاً با فرمت اسکریپت `encrypt_keys.py` انجام می‌شود: PBKDF2-SHA256 با ۲۰۰۰۰ تکرار، salt شانزده‌بایتی و AES-GCM با nonce دوازده‌بایتی.

کلیدهای قابل پشتیبانی در فایل: `NESHAN_API_KEY`، `MAPIR_API_KEY`، `GAPGPT_API_KEY`، `LIARA_API_KEY` و `LIARA_BASE_URL`. برای فایل رمزگذاری‌شدهٔ فعلی، گذرواژهٔ استفاده‌شده در دستور شما به‌عنوان پیش‌فرض سازگاری لحاظ شده است؛ هنگام ساخت فایل جدید، حتماً یک گذرواژهٔ قوی بسازید و آن را فقط در GitHub Secret با نام `KEYS_DECRYPTION_SECRET` وارد کنید.

GapGPT اولویت گفت‌وگو، تبدیل گفتار ضبط‌شده به متن و خواندن پاسخ را دارد. در خطای گفت‌وگو، برنامه به لیارا سوییچ می‌کند. اگر تبدیل صدای آنلاین در دسترس نباشد، تشخیص گفتار خود گوشی جایگزین می‌شود.

## ذخیره خانه، محل کار و اشتراک‌گذاری نقشه

با اولین لمس «خانه» یا «محل کار»، برنامه نام دلخواه می‌پرسد و مختصات و آدرس موقعیت فعلی را ذخیره می‌کند. دفعات بعد همان دکمه مستقیم مسیریابی را آغاز می‌کند. برای وارد کردن مکان از Google Maps یا نشان، در همان برنامه روی Share بزنید، `DriveMate AI` را انتخاب کنید و نام مقصد را در پنجرهٔ بازشده ویرایش یا تأیید کنید.

## بیلد در GitHub

Workflow در مسیر `.github/workflows/android.yml` قرار دارد. بعد از push به GitHub، از تب Actions می‌توان APK دیباگ را ساخت و از Artifacts دانلود کرد.

برای فعال شدن مسیر واقعی، این secrets را در GitHub تنظیم کن:

- `NESHAN_API_KEY`
- `MAPIR_API_KEY`
- `AI_API_KEY` اختیاری است

بدون کلیدها هم پروژه باید build شود، اما دریافت مسیر واقعی خطا می‌دهد.

## فایل‌های صوتی

برای سبک ماندن مخزن، task گرادل هنگام build تعداد ۴۳ فایل WAV معتبر و ساکت تولید می‌کند. برای نسخه واقعی، فایل‌های صوتی فارسی را با همین نام‌ها در `app/src/main/res/raw/` قرار بده تا به‌جای placeholder استفاده شوند.

نام چند فایل مهم:

- `turn_left.wav`
- `turn_right.wav`
- `arrived.wav`
- `route_recalculated.wav`
- `start_navigation.wav`
- `gps_lost.wav`
- `command_unknown.wav`

## توسعه بعدی

نسخه دوم می‌تواند جست‌وجوی جای پارک، پیدا کردن خودرو، یادآوری مکانی و مسیرهای پرتکرار را اضافه کند. نسخه سوم می‌تواند گفت‌وگوی طبیعی‌تر، پیشنهاد استراحت، تحلیل رانندگی و ثبت سفرها داشته باشد.
