# DriveMate AI / همراه راننده

دستیار رانندگی فارسی برای Android با تمرکز بر فرمان صوتی، مسیریابی کم‌لمس، راهنمای صوتی و همراهی آنلاین کوتاه در طول سفر.

این پروژه جایگزین اپلیکیشن نشان یا Google Maps نیست. مسیر هندسی و داده مکان را از سرویس‌های نقشه می‌گیرد و مدل آنلاین فقط برای فهم فرمان طبیعی و پاسخ یا هشدار صوتی کوتاه استفاده می‌شود.

## داده‌های ترافیک و ایمنی

کلید نشان فعلی می‌تواند سرویس «مسیریابی با در نظر گرفتن ترافیک + تخمین زمان رسیدن» را فعال کند. این برای انتخاب مسیر و ETA ترافیک‌محور مفید است.

دوربین سرعت، پلیس، دست‌انداز، انسداد مسیر و سرعت مجاز قانونی تنها زمانی اعلام می‌شوند که یک API یا SDK رسمی، این داده را برای اپ ثالث بازگرداند. مدل زبانی مجاز نیست این داده‌ها را حدس بزند. سرعت بالای GPS نیز هشدار ایمنی است و به معنی تشخیص تخلف قانونی نیست.

برای تکمیل این بخش، از پشتیبانی نشان endpoint و نمونه پاسخ رسمی این موارد را درخواست کنید:

- ترافیک جاری و تغییر ETA
- Traffic incident و road closure
- speed camera، police و speed bump
- speed limit برای هر قطعه جاده

## فرمان‌های صوتی نمونه

- «برو خانه»
- «اینجا خانه است»
- «برو به میدان آزادی»
- «نزدیک‌ترین پمپ بنزین کجاست؟»
- «یک مجتمع خدماتی پیدا کن»
- «صدایت را بلندتر کن»
- «مسیر بعدی را تکرار کن»
- «ترافیک مسیر چطور است؟»

پرسش‌های صریح به مدل ارسال می‌شوند. عبارت‌های غیرسوالی به مقصد، مکان ذخیره‌شده یا جستجوی مکان تبدیل می‌شوند.

## هوشمندی رانندگی

از «تنظیمات» > «هوشمندی رانندگی» یکی از این حالت‌ها را انتخاب کنید:

- **هوشمند اقتصادی (پیش‌فرض):** فرمان‌های شناخته‌شده، راهنمای مسیر، خروج از مسیر، سرعت، استراحت و هشدارهای ثابت آفلاین و فوری هستند. مدل فقط برای پرسش طبیعی، فرمان ناشناخته یا تحلیل اختیاری استفاده می‌شود.
- **هوشمند کامل:** شروع سفر، دستورهای پیچ، هشدارهای مسیر، خروج از مسیر، تغییر مسیر، رسیدن و توقف ابتدا در صف اولویت‌دار مدل قرار می‌گیرند و با TTS آنلاین پخش می‌شوند. هشدارهای ایمنی حداکثر ۱٫۵ ثانیه و پیام‌های عادی مسیر حداکثر ۳ ثانیه منتظر پاسخ آنلاین می‌مانند؛ اگر پاسخ نرسد یا کلید/اینترنت در دسترس نباشد، فایل WAV آفلاین همان رویداد پخش می‌شود و پاسخ دیررس دور ریخته می‌شود.

صف هوشمند سه اولویت دارد: ایمنی، رانندگی و گفتگو. هر درخواست شناسه، زمان انقضا و وضعیت دارد تا پاسخ منقضی یا لغوشده هرگز پخش نشود. فقط یک درخواست مدل در هر زمان پردازش می‌شود تا هزینه و تداخل پاسخ‌ها کنترل شود.

در حالت کامل، حدود ۱۵ دقیقه پیش از یادآوری استراحت، متن هشدار در پس‌زمینه آماده می‌شود و در زمان مناسب بدون تأخیر پخش خواهد شد.

فرمان‌های ساده پس از تبدیل گفتار توسط موتور محلی برنامه پردازش می‌شوند. در نبود کلید یا اینترنت، برنامه از تشخیص گفتار روی‌دستگاه Android با زبان `fa-IR` استفاده می‌کند؛ این قابلیت به نصب بودن بسته تشخیص گفتار آفلاین فارسی روی گوشی و Android 12 یا بالاتر وابسته است و هیچ صفحه Google باز نمی‌کند.

## حریم خصوصی و حافظه مدل

مکان‌ها و تاریخچه سفر در خود گوشی نگهداری می‌شوند. هنگام درخواست پاسخ هوشمند، فقط مقصد فعال، حداکثر شش نام مکان ذخیره‌شده و پنج مقصد اخیر به مدل ارسال می‌شود. مختصات کامل و تمام تاریخچه سفر به مدل ارسال نمی‌شود.

## پشتیبان‌گیری

از دکمه «پشتیبان‌گیری و بازیابی» استفاده کنید:

1. «ساخت نسخه خودکار در گوشی» فایل آخرین پشتیبان را در فضای اختصاصی برنامه می‌سازد.
2. «ذخیره دستی یا Google Drive» فایل JSON را در محل انتخابی شما ذخیره می‌کند؛ در فایل‌گزین Android می‌توان Google Drive را انتخاب کرد.
3. «ارسال فایل پشتیبان» فایل JSON را با برنامه دلخواه به اشتراک می‌گذارد.
4. «بازگردانی از فایل» مکان‌ها، مقصدهای اخیر، سفرها و تنظیمات را جایگزین می‌کند.

Android Auto Backup نیز برای SharedPreferences برنامه پیکربندی شده است. همگام‌سازی ابری آن به تنظیمات Backup گوشی و حساب Google کاربر وابسته است.

## کلیدها و Secrets

برنامه در شروع تلاش می‌کند کلیدهای رمزگذاری‌شده را از منبع تنظیم‌شده دریافت کند. نام‌های پشتیبانی‌شده در payload رمزگذاری‌شده:

- `NESHAN_API_KEY`
- `MAPIR_API_KEY`
- `GAPGPT_API_KEY`
- `LIARA_API_KEY`
- `LIARA_BASE_URL`

برای GitHub Actions، Secrets زیر را در مخزن وارد کنید:

- `NESHAN_API_KEY`: کلید متنی سرویس‌های نشان، نه فایل `neshan.license`
- `MAPIR_API_KEY`
- `AI_API_KEY`: اختیاری، برای سازگاری با تنظیم قبلی
- `KEYS_DECRYPTION_SECRET`: گذرواژه رمزگشایی payload کلیدها

فایل `neshan.license` فقط هنگام افزودن Android SDK نشان کاربرد دارد و باید با package name و SHA-1 کلید امضای APK سازگار باشد.

## بیلد در GitHub

Workflow در `.github/workflows/android.yml` قرار دارد. پس از push به شاخه `main` یا `master`، GitHub Actions APK دیباگ را می‌سازد و در Artifacts با نام `DriveMate-AI-debug-apk` قرار می‌دهد.

## معماری

- `routing/`: نشان، map.ir، جستجوی مکان و موتور مسیریابی
- `ai/`: کلیدهای زمان اجرا، گفت‌وگو، STT/TTS آنلاین و همراه هوشمند سفر
- `voice/`: تشخیص فرمان‌های فارسی و پخش WAV/TTS
- `storage/`: مکان‌ها، سفرها و پشتیبان JSON
- `location/`: GPS، Geocoder و تحلیل لینک‌های اشتراک‌گذاری‌شده

## امکانات پیشنهادی بعدی

- SDK یا API رسمی داده ترافیک و مخاطرات مسیر
- اتصال Bluetooth OBD-II برای سوخت و داده خودرو
- ثبت اختصاصی محل پارک و پیدا کردن خودرو
- گزارش هزینه سفر با نرخ سوخت، عوارض و داده کاربر
- تشخیص خستگی با رضایت صریح کاربر و پردازش امن دوربین
